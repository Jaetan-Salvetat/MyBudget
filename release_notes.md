# MyBudget v1.0.0 (2025-05-07)

## 🚀 First Release

This is the initial release of MyBudget, a personal finance management application designed to help users track their expenses, revenues, loans, and accounts.

## ✨ Features

- **Dashboard**: Overview of financial status with income, expenses, and balance
- **Accounts Management**: Create and manage multiple accounts
- **Expense Tracking**: Log and categorize expenses
- **Revenue Tracking**: Record all sources of income
- **Loan Management**: Track ongoing loans with payment schedules
- **Categories**: Customizable expense categories
- **Data Export/Import**: Backup and restore your financial data
- **Multiple Themes**: Choose between light and dark themes

## 📱 Compatibility

- Android: 5.0 (Lollipop) and above
