# Settings Flow

## Principe

100% manuel. Les préférences sont de l'intention user par définition — pas d'automatisation possible.

## Layer 3 (tout)

| Setting | Détail |
|---|---|
| Gestion des catégories | Rename, icon, color, delete |
| Gestion des bénéficiaires | CRUD |
| Gestion des comptes | CRUD |
| Import / Export | Voir `import_export_flow.md` |
| Thème | Clair / Sombre / Système |
| Notifications | On / Off |
| Version / À propos | Lecture seule |

## Pas de LLM

Les settings n'ont aucun besoin d'inférence. L'user sait ce qu'il veut configurer.
